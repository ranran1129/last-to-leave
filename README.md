# LAST TO LEAVE ─ 終演後のマリンメッセ福岡

2024年12月5日、日向坂46「Happy Magical Tour 2024」福岡公演2日目・濱岸ひより卒業セレモニーが終わった直後の
マリンメッセ福岡A館に、たった一人取り残された「おひさま」の実写風ポイント＆クリック脱出ゲームです。

**非公式のファンメイド・フィクションです。** 実在の公演を舞台にしていますが、登場する設備・スタッフ・書類・
会場の非公開エリアはすべて創作で、実在施設の設備や解錠手順を再現したものではありません。
公式の楽曲・音源・映像・写真・ロゴは一切使用しておらず、画像は生成AIで人物・文字なしに生成したもの、
効果音と環境音はすべてWebAudioによるプロシージャル合成です。

- 想定プレイ時間：60〜100分（メイン謎8問＋最終メタ謎、ヒントは3段階＋答え）
- 遊べる環境：PC（マウス）／スマートフォン・タブレット（タップ）。進行は自動保存されます。

## 遊ぶ

公開版： https://ranran1129.github.io/last-to-leave/

ローカルで動かす場合：

```bash
npm install
npm run dev
```

ブラウザで表示されたURL（既定 http://localhost:5173 ）を開きます。ビルド済みを確認する場合：

```bash
npm run build
npm run preview
```

## テスト

```bash
npm test
```

パズル依存グラフの非循環性・全問の到達可能性・解答判定・セーブデータの移行・アセットの存在を検証します。

```bash
npx playwright test
```

PC（1280×800）とスマートフォン相当（Pixel 5）の両方で、ヒントを使わずにタイトルからエンディングまで
通しでプレイし、コンソールエラーと404アセットが無いことを確認します。セーブ→リロード→CONTINUE、
RESET、ヒントのゲート（情報不足の表示）も検証します。

## 構成

```
src/
  game/      state store・セーブ・パズル定義と解答判定・シーン定義・世界データ・自動メモ
  closeups/  資料（書類・写真）と装置UI（パネル／錠／音響卓／照明卓／分電盤／制御盤）
  scenes/    写真の上に重ねる標識・ランプ・状態変化のSVGレイヤー
  components/ 画面（タイトル・導入・探索・スマホ・エンディング・結果）
  audio/     WebAudioによる環境音と効果音、エンディングのモチーフ
tools/       画像生成の取得・変換スクリプト（生成プロンプトは images.json 参照）
docs/        GAME_DESIGN.md（**解答を含む開発用ドキュメント／ネタバレ注意**）
```

パズルの答えと状態遷移は `src/game/puzzles.ts` と `src/game/data.ts` に集約してあり、
画面表示（`closeups/`）とは分離しています。問題の内容を調整するときはデータ側だけを触ります。
